# Only Cars Club — site estático

## Como testar

Abra o arquivo `index.html` diretamente no Chrome.

## Estrutura

- `index.html`: Home
- `sobre.html`: O Clube
- `loja.html`: Loja
- `contato.html`: Contato
- `eventos.html`: Eventos (acesso pelo botão da Home)
- `assets/css/style.css`: estilos
- `assets/js/main.js`: animações e carrossel
- `assets/images/`: imagens e logotipo

## Atualizações e cache

Os arquivos CSS e JavaScript usam um identificador de versão na URL, como
`?v=20260724-1`. A cada nova entrega esse número será alterado para o navegador
carregar a versão nova.

Para publicar no GitHub Pages, envie todo o conteúdo desta pasta mantendo
`index.html` na raiz.
